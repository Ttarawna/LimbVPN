# Limb VPN (Android)

Минималистичный клиент для протокола mieru. Ядро: Mihomo. Интерфейс: Flutter.
Сборка идёт на GitHub

## Что внутри

- `lib/`, `test/`: интерфейс Flutter, управление VPN через Android MethodChannel,
  разбор ссылок mierus://, генератор конфига Mihomo и проверка/установка обновлений
  из расширенных настроек приложения.
- `core/`: обёртка на Go вокруг Mihomo (собирается в библиотеку для Android).
- `android_overlay/`: Kotlin-код (служба VPN, ядро в отдельном процессе, kill switch,
  восстановление VPN после обновления, диагностика, защищённое хранилище), манифест, иконки.
- `tools/`: подготовка Android-проекта и патч библиотеки sing-tun при сборке.
- `.github/workflows/android.yml`: автосборка и публикация релиза.

## Маршрутизация и DNS

Российские домены и IP-адреса идут напрямую, остальной трафик — через mieru.
DNS российских доменов направляется к локальным DNS-серверам активной сети;
прочие домены разрешаются удалённым DoH через прокси. Системный DNS-fallback
отключён, а актуальные DNS-адреса сети перечитываются при каждом старте ядра.
Исключённые из VPN приложения
(в том числе автоматически определяемые российские) обходят и VPN-фильтрацию,
и её DNS-защиту. Для доменного адреса самого VPN-сервера Android должен
определить IP до установления туннеля — это отдельный bootstrap-запрос.

Опциональная блокировка рекламы добавляет правило Mihomo для
`category-ads-all` перед правилами разделения RU/остального трафика. Она
блокирует известные рекламные домены, но не рекламу, встроенную в контент с
того же домена; охват зависит от наличия категории в используемом geosite-файле.

Плитка «Limb VPN» доступна в быстрых настройках Android. Она показывает состояние
службы и запускает сохранённый профиль или останавливает VPN. При смене
Wi-Fi/мобильной сети ядро перезапускает исходящие соединения, сохраняя туннель.

После перезагрузки VPN автоматически не запускается: подключение выполняется
пользователем из приложения или плитки. Возобновление после обновления приложения
сохранено. Локальные замеры этапов содержат только название этапа и длительность,
без адресов, учётных данных или конфига.
