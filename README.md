# Limb VPN (Android)

Минималистичный клиент для протокола mieru. Ядро: Mihomo. Интерфейс: Flutter.
Сборка идёт на GitHub, ставить Flutter, Go и Android Studio не нужно.

## Как получить APK

1. Загрузите содержимое этого архива в репозиторий (с заменой файлов), включая скрытую
   папку `.github`.
2. Вкладка **Actions**, workflow «Android APK», **Run workflow**.
3. Через 15-30 минут скачайте APK из раздела Artifacts (или из Releases, если настроен ключ).

Если сборка упала, откройте её, найдите шаг с ошибкой и пришлите текст из лога этого шага.

## Автообновление (настроить один раз)

Приложение само проверяет раздел Releases репозитория и предлагает обновиться.
Android ставит обновление поверх установленной версии только если оно подписано тем же
ключом, поэтому нужен постоянный ключ подписи:

1. Откройте файл `limb_signing_secrets.txt` (он не входит в репозиторий) и добавьте два
   секрета в Settings, Secrets and variables, Actions: `KEYSTORE_PASSWORD` и `KEYSTORE_BASE64`.
2. Удалите прежнюю версию приложения с телефона и поставьте новую (один раз, потому что
   прежняя подписана временным ключом).
3. Дальше каждая сборка с новой версией в `pubspec.yaml` (строка `version:`) публикуется в
   Releases, а приложение предлагает обновиться.

Репозиторий должен быть публичным, иначе приложение не сможет читать релизы.
Не забывайте увеличивать версию в `pubspec.yaml` при каждом выпуске.

## Что внутри

- `lib/`, `test/`: интерфейс на Flutter, разбор ссылок mierus://, генератор конфига Mihomo.
- `core/`: обёртка на Go вокруг Mihomo (собирается в библиотеку для Android).
- `android_overlay/`: Kotlin-код (служба VPN, ядро в отдельном процессе, kill switch,
  автозапуск, обновление, защищённое хранилище), манифест, иконки.
- `tools/`: подготовка Android-проекта и патч библиотеки sing-tun при сборке.
- `.github/workflows/android.yml`: автосборка и публикация релиза.
