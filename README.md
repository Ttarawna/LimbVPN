# Limb VPN (версия 0.8.1, Android)

Минималистичный клиент для протокола mieru. Ядро: Mihomo. Интерфейс: Flutter.
Сборка идёт на GitHub, ставить Flutter, Go и Android Studio не нужно.

## Как получить APK

1. Создайте аккаунт на github.com и новый **приватный** репозиторий (New repository).
2. Загрузите в него всё содержимое этого архива: Add file, Upload files, перетащите
   все файлы и папки, включая скрытую папку `.github`. Нажмите Commit changes.
   Если `.github` не загрузилась: Add file, Create new file, в имени файла наберите
   `.github/workflows/android.yml` и вставьте туда содержимое одноимённого файла из архива.
3. Откройте вкладку **Actions**. Если GitHub попросит, разрешите запуск workflows.
4. Выберите слева «Android APK», нажмите **Run workflow**, затем зелёную кнопку.
5. Через 15-30 минут сборка завершится. Откройте её, внизу в разделе Artifacts скачайте
   `limb-vpn-apk`, распакуйте и установите `app-release.apk` на телефон
   (разрешите установку из неизвестных источников).

Если сборка упала (красный крест), откройте её, найдите шаг с ошибкой и пришлите мне
текст из лога этого шага.

## Что внутри

- `lib/`, `test/`: интерфейс на Flutter, разбор ссылок mierus://, генератор конфига Mihomo.
- `core/`: обёртка на Go вокруг Mihomo (собирается в библиотеку для Android).
- `android_overlay/`: Kotlin-код VpnService и манифест.
- `tools/patch_android.py`: подготовка Android-проекта при сборке.
- `.github/workflows/android.yml`: автосборка.

## Что проверить после установки

1. Добавьте ссылку `mierus://логин:пароль@сервер?port=...&protocol=TCP`.
2. Нажмите кнопку, разрешите VPN-подключение.
3. Российские сайты должны открываться напрямую, остальные через сервер
   (сайт «мой IP» покажет IP сервера).
4. В скрытом меню (5 нажатий в левый нижний угол) откройте «Системная блокировка без VPN»
   и включите её для приложения: это настоящий kill switch на Android.
